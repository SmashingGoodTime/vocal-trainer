### The ASIO warning, stated plainly

`VT_ENABLE_ASIO` defaults to **OFF** and should stay off for anything you distribute.

Building with it ON links GPLv3 code into the Standalone. For a tool you build and keep on
your own machine that has no consequence — no distribution means no copyleft obligation. The
moment you publish that binary, you must either release the whole thing under GPLv3 or hold
Steinberg's proprietary ASIO licence.

Any binary attached to a release of this project is built with `VT_ENABLE_ASIO=OFF`, and
falls back to WASAPI.

## Model weights are not redistributable

The BS-Roformer / UVR separation checkpoint that `audio-separator` downloads is licensed
**vaguely or not at all**, which is typical of the UVR model ecosystem. Running it locally is
fine. Bundling it, mirroring it, or attaching it to a release is not.

Weights are cached outside the repository, in
`%LOCALAPPDATA%\VocalTrainer\separator-models`, partly so they cannot be committed by
accident.

## Song material is not included

`songs/` is gitignored except for `songs/synth-demo/`, which is synthesised test audio
generated by this project and carries no third-party rights.

Charts you generate from commercial recordings are **derivative works** — the aligned lyrics
especially. Keep them local. Do not commit them, and do not attach them to a release.
